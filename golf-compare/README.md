# 그린피 레이더 — 강남 90분권 골프장 가격 비교

강남 기준 이동시간과 날짜별 그린피(평일/주말/공휴일)를 비교하는 웹앱입니다.

- 웹앱 소스: `app.html` (Claude Artifact로 게시됨 — 링크는 대화창 참고)
- 골프장 목록: `courses_seed.json` (강남 90분권 후보, 이름만 — 이동시간은 아직 실측 전)
- 이동시간 실측 스크립트: `fetch_distances.py`

## 왜 스크립트를 로컬에서 돌려야 하나요?

이 저장소를 다루는 Claude 원격 세션은 조직 네트워크 정책상 카카오 API 도메인
(`dapi.kakao.com`, `apis-navi.kakaomobility.com`)에 접근할 수 없습니다. 또한 게시된
웹앱(Artifact) 자체도 브라우저 보안 정책상 카카오 API를 직접 호출할 수 없습니다.
그래서 이동시간 계산은 **사용자 PC에서 직접 실행하는 스크립트**로 처리하고, 그
결과만 웹앱에 붙여넣어 반영하는 구조로 만들었습니다.

## 사용 순서

1. [카카오 디벨로퍼스](https://developers.kakao.com/console/app)에서 애플리케이션을 만들고
   **REST API 키**를 발급받습니다. 좌측 메뉴 **제품 설정 → 카카오모빌리티**에서
   길찾기(내비게이션) API 사용 신청도 해두세요(무료 티어로 충분).
2. 로컬 터미널에서:
   ```bash
   export KAKAO_REST_API_KEY=발급받은키
   cd golf-compare
   python3 fetch_distances.py
   ```
   기본값은 `courses_seed.json`의 26개 후보를 대상으로 강남역 기준 이동시간을 계산하고,
   90분 이내인 곳만 `distances_output.json`으로 저장합니다.
3. `distances_output.json` 파일 내용을 통째로 복사해서, 웹앱의
   **"이동시간 실측 반영"** 패널 텍스트 상자에 붙여넣고 **"이동시간 데이터 적용"**을 누릅니다.
   이름이 일치하는 골프장의 이동시간이 "지역 추정"에서 "실측"으로 갱신됩니다.
4. 웹앱에서 골프장별로 **"가격 편집"**을 눌러 그린피를 직접 입력합니다. 국내 골프장은 같은 날짜라도
   시간대(새벽/1부, 오전/2부, 오후/3부, 트와일라잇, 야간)에 따라 요금 차이가 크므로, 골프장 홈페이지에서
   확인한 시간대마다 날짜유형(평일/주말/공휴일) × 시간대 조합으로 가격을 하나씩 추가합니다. 한 골프장에
   여러 개를 등록할 수 있고, 비교표에서는 상단의 "시간대" 필터에 맞는 최저가가 자동으로 표시됩니다.
   그린피는 실시간 자동 수집이 아니라 사용자가 확인한 값을 기록하는 방식입니다 — 국내 골프장 그린피는
   예약 시점·시간대·플랫폼별로 수시로 바뀌고 공개 API가 없기 때문입니다. 골팡 같은 통합 예약 앱보다
   개별 골프장 홈페이지 확인이 더 정확하다면, 홈페이지 기준으로 입력하고 메모란에 확인 일자를 남겨두세요.
5. 목록에 없는 골프장은 웹앱의 **"골프장 추가"**에서 바로 추가할 수 있습니다
   (이름/지역/추정 이동시간 입력 → 이후 2~3단계로 실측 반영).

## 후보 골프장 목록에 대한 참고사항

`courses_seed.json`의 이름/지역/홈페이지는 2026-09-09 기준 웹 검색으로 실재 여부를
한 번 재확인한 값입니다. 처음 만들 때는 일반적으로 알려진 이름으로 시작했는데,
검증해보니 실제로 존재하지 않거나(미사관광CC, 세경CC, "이천CC"), 위치가 틀렸거나
(신라CC→여주 아닌 이천으로 잘못 기재, 서원힐스·블루헤런→양평 아닌 파주/여주, 베어크리크→
가평 아닌 포천, 라비에벨CC→화성이 아니라 강원 홍천 소재라 90분권 밖), 다른 골프장과
혼동된(아시아나CC는 실제로 용인 소재라 안성 슬롯을 실재하는 안성컨트리클럽으로 교체) 항목이
여럿 나와서 바로잡았습니다. 그래도 홈페이지 주소나 지역이 바뀌었을 수 있으니, 강남
90분권에 있는데 목록에 없거나 정보가 다른 골프장은 `courses_seed.json`에 직접
추가하거나 웹앱에서 바로 추가·수정하세요.

## 그린피를 대신 찾아줄 수 있나요?

Claude가 이 세션에서 골프장 홈페이지를 직접 열어보는 것은 네트워크 정책상 불가능하고,
일반 웹 검색 결과만으로는 시간대별 정확한 요금표를 안정적으로 얻기 어렵습니다. 두 가지
보조 스크립트를 상황에 맞게 쓰세요.

### 방법 A — `fetch_fee_pages.py` (가볍지만 제한적)

로그인/자바스크립트 없이 정적으로 노출된 요금만 잡을 수 있습니다. 설치 없이 바로 실행:

```bash
cd golf-compare
python3 fetch_fee_pages.py
```

실제로 대부분의 사이트가 로그인/JS 뒤에 요금을 숨겨둬서, 이 방법으로는 거의 못 잡는
경우가 많습니다(24곳 중 1곳만 잡힌 사례 있음). 그런 경우 방법 B를 쓰세요.

### 방법 B — `browse_fee_pages.py` (실제 브라우저, 로그인 지원 — 권장)

실제 크롬 창을 띄워 자바스크립트까지 렌더링한 화면을 읽습니다. 로그인이 필요한 사이트는
뜬 브라우저 창에서 **직접** 로그인하면 되고(비밀번호는 Claude에게 전달되지 않음), 그
세션은 로컬 폴더에 저장돼 다음부터는 다시 로그인할 필요가 없습니다.

```bash
pip3 install playwright
playwright install chromium     # 최초 1회, 브라우저 다운로드(수백 MB)
cd golf-compare
python3 browse_fee_pages.py
```

크롬 창이 뜨고 골프장을 하나씩 방문합니다. 로그인이 필요해 보이면 터미널에 안내가
뜨고 멈추니, 그 창에서 로그인만 하고 터미널로 돌아와 Enter를 누르면 이어집니다.
전체 24곳이 부담스러우면 일부만 먼저 테스트할 수 있습니다:

```bash
python3 browse_fee_pages.py --only "88컨트리클럽,신라CC"
```

완료되면 `fee_pages_browsed.txt`(방법 A는 `fee_pages_dump.txt`)가 생깁니다. 이 파일
내용을 Claude 대화에 붙여넣으면, 실제로 읽어올 수 있었던 값을 골라 웹앱 가격 데이터에
반영해 드립니다.

### 방법 C — `browse_reservation_pages.py` (실제 예약가, 날짜 지정 — 가장 정확하지만 가장 불안정)

공지사항용 요금 페이지 대신, "예약" 메뉴로 들어가서 **지정한 날짜**의 실제 예약가를
읽으려고 시도합니다. 예약 시스템은 사이트마다 달력 UI가 전부 달라서(날짜 입력칸,
커스텀 달력, 코스 먼저 선택 등) 모든 곳에서 성공하지는 않습니다 — 안 되는 곳은
"날짜 선택 실패"로 표시되니 그런 곳만 직접 열어보시면 됩니다.

```bash
cd golf-compare
python3 browse_reservation_pages.py --date 2026-09-12
```

로그인 처리 방식은 방법 B와 동일(브라우저 창에서 직접 로그인, 세션 재사용)합니다.
결과는 `reservation_dump.txt`에 저장됩니다.

## 공휴일 판정

웹앱은 2026년 대한민국 공휴일(대체공휴일 포함)을 참고용으로 내장하고 있습니다. 설날·추석·
부처님오신날처럼 음력 기준 연휴는 매년 정부 발표를 통해 확정되므로, 확실하지 않다면
웹앱 상단의 "공휴일 요금 강제 적용" 토글로 직접 조정하세요.
